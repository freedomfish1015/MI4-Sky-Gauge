# 2026.10.21-candidate-r2 更新说明

此版在上一份干净镜像上增量构建，不重新克隆开发手机，也不带入蓝牙配对、Wi-Fi、轨迹、日志或账号。安装仍清空手机数据。

## 蓝牙充电恢复

修复充电模式里重启后蓝牙残留“软件禁用”的问题。进入充电模式前把蓝牙原状态保存到仅root可读的恢复日志；下次正常启动等待rfkill初始恢复后恢复原意图。原本就关闭的蓝牙继续关闭，不强制打开，不修改Wi-Fi或配对。

10项恢复日志测试、13项原充电流程测试通过；开发机蓝牙即时解除禁用后，用户确认可以扫描。新版守护服务已热部署，未额外执行亏电重启来模拟充电中断。

## 自动 Fastboot 兔子修复

首次启动由 `mi4-fastboot-screen-fix.service` 自动检查，不要求机主额外确认。

- 已知原厂aboot本来就有兔子：保留原样，不写分区。
- 已修复版本：记录完成，不重复写。
- 完全匹配已验证旧Sky引导：只写一个512字节扇区，其中只有4字节指令改变；先备份、完整读回校验，失败尝试恢复原扇区。正常开机Sky图不变。
- 未知版本：不尝试移植或刷整份aboot，记录不支持后继续正常启动。
- 可修复但USB未连接、电量不足50%、电压低于3.8V或供电不稳：本次不写，留待后续启动重试。不能为了自动化取消这些保护。

不随镜像复制本机整份aboot，不改IMEI/校准分区，不因修复自动重启。已确认的本机兔子画面、USB Fastboot查询、正常Sky/仪表/触摸都通过。将此自动首次启动策略移植到新机尚未做全量安装验收。

可在系统终端查看状态：

```sh
sudo cat /var/lib/mi4-sky/fastboot-repair/status.json
sudo mi4-sky-fix-fastboot --check
```

aboot是救援入口，写坏可能无法进入Fastboot，EDL未实测。自动补丁只支持完全匹配的哈希，不能把它当作所有Mi4固件的通用补丁。

## 仍未完成

Windows候选安装器目前会因部分原厂Mi4不报告 `version-bootloader`、`partition-size:boot` 而拒绝安装。这次更新镜像没有直接删除这些安全检查，**仍不适合作为已验证的通用一键刷机稳定版发布**。

旧PDF的基础使用操作仍适用，但关于“绝不写aboot”的旧描述由本文取代：Windows阶段仍只写userdata/boot，新增首次启动策略可能按上面的严格条件修复aboot。请优先阅读R2版本说明和更新后的PDF。

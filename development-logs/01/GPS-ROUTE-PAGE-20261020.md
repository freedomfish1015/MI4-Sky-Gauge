# GPS离线轨迹页（2026-10-20已部署）

## 操作

- 仪表**向上滑**进入轨迹，轨迹页向下滑或左上按钮返回。
- 仪表向下滑仍为实时LOG，左滑仍为设置。
- 设置 → G值/GPS → 查看行驶轨迹，也能进入。
- 上一条=更早记录，下一条=更新记录；默认最新非空CSV。新空记录只在当前正在记录时显示。
- 右侧＋/－缩放1–16倍，全览重置缩放并居中；最新回到当前记录/最新文件。
- 开始/停止记录复用现有motion-control.json与mi4_motiond，不在仪表中另开一套GPS写入器。
- 当前室内无定位时可查看历史；新路线必须点开始记录，并等待有效GPS定位。

这是**离线线路图，不含在线道路地图/导航**。绿起点、红最近记录点/终点；起终点重合时用绿圈红心避免遮盖。
没有有效定位不会添加模拟坐标；绘制已有实际GPS记录。坐标/路线不上传网络。

## 绘制和数据边界

- 数据目录 `/var/lib/obd-motion/tracks/*.csv`，现有GPX/GNSS卫星记录不修改。
- 显示文件日期使用北京时间。原始UTC文件名不改。
- 验证有限经纬度/范围/误差0–100m/带时区UTC；跳过非法行、重复或倒退时间戳。
- 时间间隔超过5秒、非法行后续点、明显短时跳点处分段，不把长定位中断用一条直线跨接。
- CSV并不包含每次短暂失锁状态，无法恢复所有短暂失锁细节；无新增虚构点或预测轨迹。
- 本地米制近似投影，北向上，有比例尺；不是全球精密制图。
- 长度是有效相连GPS点的折线距离估算，不是里程表/道路匹配距离；GPS漂移可能增加估算长度，分段缺失可能低估。
- 历史最多展示最近200个非空/当前CSV；不删除更早文件。
- 后台增量读取每次最多256KiB，文件上限64MiB，不在渲染线程读CSV。
- 绘图点数上限12000，超限显示抽稀，保留起终点与分段边界；点计数、已累计长度仍基于原始读入的有效点。原CSV不改、不删。
- 页面约2Hz重绘、后台最多1Hz请求文件增量；普通仪表页不持续加载路线，不改变BLE/低延迟参数。

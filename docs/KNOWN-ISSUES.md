# 已知问题与不可宣称完成的事项

1. **整机安装阻断**：实测原厂Fastboot product=MSM8974、kernel=lk，但version-bootloader/boot大小为空。安装器会停止；不能用空值猜测32MiB或关闭安全检查。
2. **硬件范围**：只验收Mi4 LTE/JDI/mxt640t。其他屏幕、触控、非LTE、改装机未验证。
3. **新机首启**：没有另一台手机清空安装/扩容/完整硬件验收。已有手机稳定运行不等于安装流程稳定。
4. **素材和厂商二进制**：原机动漫图片、视频、商标图片及高通/原厂固件未作为GPL代码收录。开源树可缺省显示无图布局；未自动生成可随意公开的整机镜像。
5. **启动衔接**：视频已取消、光标/版本文字已处理，但原厂/内核/显示接管仍可能短黑，不保证完全无缝。
6. **定位**：观测卫星不等于有效定位，室内/车膜影响接收。日志能分类系统，不代表已证实所有北斗能力或保证可靠首次定位。
7. **G值**：动态加速度可自动回中，但不是经过车辆安装姿态和轴向标定的专业测量设备。
8. **事件系统**：原版C核心与FFI可测试，不代表所有事件动作/主题效果已连接到可见页面。
9. **小程序**：没有正式AppID或发布包；只提供手机端热点/JSON配对/下载接口。
10. **引导修复**：只支持严格匹配旧aboot；未知版本跳过，EDL未验证。新机首次自动写入尚未完整验收，不能泛化为任意机型补丁。
11. **可复现性**：提供源码快照、版本、配置和导出设备树，但整机历史镜像的字节级重建尚未证明。详见REPRODUCIBILITY。
12. **基础脚本许可待核对**：Umeko本地快照未见明确LICENSE，四个原样继承脚本未混入GPL源树；对应服务引用仍在，搭建完整系统前须自行取得相应授权组件或另行实现，见hardware/umeko-integration.md。
